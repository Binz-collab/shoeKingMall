# 결제 모듈 프로젝트

## 프로젝트 개요

- 신발 쇼핑몰에서 카드 간편 결제를 위한 결제 모듈입니다.
- 사용자가 안전하게 결제 정보를 등록하고, 등록된 카드로 결제할 수 있는 기능을 제공합니다.
- PC와 모바일 환경 모두에서 최적화된 반응형 UI를 제공합니다.
- 참여한 팀원: Binz

이 결제 모듈은 고객이 상품 구매 시 카드 정보를 입력하고, 등록된 카드를 관리하며, 안전하게 결제를 진행할 수 있도록 도와주는 모달 컴포넌트입니다.

## 개발 환경

- 운영체제: Windows 10
- 에디터: Visual Studio Code
- 패키지 매니저: npm
- 버전 관리: Git, GitHub

## 사용한 프레임워크, 라이브러리, 언어

- React (Vite)
- JavaScript (ES6)
- CSS
- React Router (라우팅)
- gh-pages (배포용)

## 설치 및 실행 방법

프로젝트를 로컬에서 실행하기 위한 설치 방법과 명령어

```bash
npm install
npm run dev
```

배포(깃허브 페이지)
```bash
npm run deploy
```

## 컴포넌트 구조

주요 컴포넌트들의 구조와 역할

### 핵심 컴포넌트
- `App`: 전체 앱의 프레임, 라우팅, 전역 상태 관리
- `NavigationBar`: 상단 네비게이션 바, 장바구니 아이콘 및 카운트 표시
- `ProductList`: 상품 목록 표시 및 장바구니 담기 기능
- `MyCreditCardList`: 등록된 카드 목록 표시 및 관리
- `RegisterNewCard`: 새로운 카드 등록 폼

### 결제 관련 컴포넌트 (구현 예정)
- `PaymentForm`: 결제 정보 입력 폼
- `CardInput`: 카드 번호, 유효기간, CVC 입력 필드
- `PaymentResult`: 결제 성공/실패 결과 표시

## 주요 기능

### 현재 구현된 기능

- **결제 정보 입력 폼**
  - 카드 번호 (4자리마다 공백 자동 추가)
  - 유효 기간 (MM/YY 형식, 자동 슬래시 추가)
  - CVC (3자리 숫자, 마스킹 처리)
  - 카드 소유자 이름 (영문 대문자)

- **실시간 유효성 검사 및 피드백**
  - 입력 값 실시간 검증
  - 필드별 상세 오류 메시지
  - 필수 입력 필드 검증

- **카드 관리 기능**
  - 등록된 카드 목록 확인 (기본 구조)
  - 카드 추가/삭제/수정
  - 기본 카드 설정
  - 결제할 카드 선택


### 구현 예정 기능

- **결제 처리 및 결과**
  - 결제 진행 상태 표시
  - 성공/실패 결과 페이지
  - 결제 내역 및 영수증

## 테스트 방법

현재 별도의 자동화 테스트는 구현되어 있지 않습니다.
기능 테스트는 브라우저에서 직접 다음 사항들을 확인하여 진행합니다.

### 테스트 항목
- 상품 "담기" 버튼 클릭 시 장바구니 카운트 증가
- 등록된 카드 목록 표시 확인
- 결제 폼 입력 필드 유효성 검사
- 결제 프로세스 진행 상태 확인

## 유의사항 및 알려진 이슈

- 현재 Safari 브라우저에서 접속 시 폰트가 다르게 보일 수 있습니다.
- 상품 데이터는 `public/data/products.json`에 하드코딩되어 있습니다.
- 새로고침 시 장바구니 카운트가 초기화됩니다 (로컬스토리지 미사용).
- 결제 모듈은 현재 기본 구조만 구현되어 있으며, 실제 결제 기능은 향후 구현 예정입니다.
